# hexlet-vibecoding

My experiments with vibecoding as part of a tutorial

## Калькулятор калорий

Веб-приложение на чистом HTML/CSS/JS без сборки и зависимостей.

- **Дневная норма** — по формуле Миффлина — Сан Жеора с учётом активности и цели (похудение −15%, поддержание, набор +15%), плюс БЖУ в пропорции 30/30/40.
- **Дневник питания** — добавление продуктов с весом порции; калорийность на 100 г подставляется из встроенного справочника или вводится вручную. Показывает сумму калорий и БЖУ и остаток до нормы. Данные сохраняются в `localStorage` браузера.

### Запуск

ES-модули не работают через `file://`, поэтому нужен любой локальный сервер:

```bash
python3 -m http.server 8080
```

Приложение: http://localhost:8080 · тесты: http://localhost:8080/tests/

### Структура

```
index.html          — разметка
css/styles.css      — стили (светлая и тёмная тема, адаптив)
js/calc.js          — чистые функции расчёта
js/foods.js         — справочник продуктов
js/app.js           — работа с DOM и хранилищем
tests/              — браузерные тесты для calc.js
```
